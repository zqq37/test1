# 灾害视频检测与时间定位系统

## 项目简介

本项目实现了一个基于深度学习的灾害视频检测与时间定位系统，能够自动识别视频中的灾害类型并定位灾害发生的时间范围。系统采用多任务学习架构，同时实现灾害类型检测和时间定位，支持多种预测模式，在灾害预警、应急响应和数据分析等领域具有重要应用价值。

## 功能特点

- ✅ **多灾种识别**：支持7种灾害类型（正常、滑坡、泥石流、森林火灾、山洪、流域性洪水、城市内涝）
- ✅ **时间定位**：精确预测灾害发生的起始时间和结束时间
- ✅ **多种预测模式**：支持单视频预测、批量预测和实时视频流检测
- ✅ **高性能模型**：基于ResNet50构建，验证准确率达88.95%
- ✅ **可视化结果**：提供直观的预测结果可视化
- ✅ **灵活配置**：支持多种参数调整，适应不同场景需求

## 技术栈

- **深度学习框架**：PyTorch 2.0+
- **计算机视觉库**：OpenCV、TorchVision
- **视频处理**：FFmpeg（通过OpenCV调用）
- **数据处理**：Pandas、NumPy
- **模型评估**：Scikit-learn
- **可视化**：Matplotlib、Seaborn

## 模型架构

系统采用多任务学习架构，包含三个核心组件：

1. **特征提取器**：使用预训练的ResNet50模型（ImageNet预训练）
   - 输入：32帧 × 224 × 224 × 3（RGB）
   - 输出：2048维特征向量
   - 冻结参数，只训练分类头

2. **灾害分类器**：多层感知机（MLP）
   - 输入：2048维特征向量
   - 隐藏层：512维
   - 输出：7个灾害类别
   - 激活函数：ReLU
   - Dropout：0.5

3. **时间定位器**：回归头
   - 输入：2048维特征向量
   - 输出：起始时间、结束时间（帧）
   - 激活函数：ReLU
   - Dropout：0.5

## 使用说明

### 1. 训练模型

```bash
# 基本训练命令
python train_stable.py

# 带参数训练
python train_stable.py --batch_size=16 --epochs=30 --lr=0.0001 --balance_classes --max_samples=950
```

**主要参数说明：**
- `--batch_size`：批次大小（默认16）
- `--epochs`：训练轮数（默认10）
- `--lr`：学习率（默认0.0001）
- `--balance_classes`：是否平衡类别（默认False）
- `--max_samples`：最大样本数（默认400）
- `--save_dir`：模型保存目录（默认./checkpoints_stable）
- `--model_type`：模型类型（simple或attention，默认simple）

### 2. 单视频预测

```bash
python predict.py --model_path="./checkpoints_stable/run_20260114_070439/best_model.pth" --video_path="视频文件路径" --visualize
```

### 3. 批量预测

```bash
python predict.py --model_path="./checkpoints_stable/run_20260114_070439/best_model.pth" --video_path="视频目录路径" --batch --visualize
```

### 4. 实时预测

```bash
# 使用视频文件
python realtime_predict.py --model_path="./checkpoints_stable/run_20260114_070439/best_model.pth" --video_path="视频文件路径"

# 使用摄像头
python realtime_predict.py --model_path="./checkpoints_stable/run_20260114_070439/best_model.pth" --video_path=0
```

**实时预测控制按键：**
- `q`：退出
- `p`：暂停/继续
- `空格`：暂停
- `Enter`：继续
- `s`：单步播放
- `r`：重新开始
- `l`：切换循环播放
- `+`：加快播放速度
- `-`：减慢播放速度

## 算法对比

系统对比了四种主流深度学习模型的性能：

| 模型 | 验证准确率 | 测试准确率 | 测试F1分数 | 总训练时间 | 综合得分 |
|------|------------|------------|------------|------------|----------|
| ResNet50 | 54.90% | 54.72% | 42.07% | 3013.0s | 0.2686 |
| EfficientNet | 54.90% | 49.06% | 40.07% | 2932.7s | 0.2501 |
| DenseNet | 47.06% | 52.83% | 37.94% | 3137.2s | 0.2477 |
| VGG16 | 52.94% | 47.17% | 38.31% | 3100.8s | 0.2336 |

**结论**：ResNet50在综合性能和训练效率上表现最佳，被选为系统的基础模型。

## 改进方向

1. **模型优化**：
   - 尝试更先进的视频理解模型（VideoMAE、TimeSformer等）
   - 引入注意力机制，提高模型对关键帧的关注度
   - 使用3D卷积处理视频时序信息

2. **数据增强**：
   - 对少数类别进行过采样（SMOTE、ADASYN等）
   - 使用Focal Loss替代CrossEntropyLoss
   - 增加旋转、裁剪、颜色抖动等数据增强技术

3. **时间定位优化**：
   - 改进时间定位头，提高时间预测精度
   - 引入时序注意力机制，关注灾害发生的关键时间段
   - 使用更精确的时间标注方法

4. **部署优化**：
   - 模型量化和剪枝，减小模型大小
   - 支持边缘设备部署
   - 提供实时推理API
